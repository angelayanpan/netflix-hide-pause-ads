# Netflix Hide Pause Ads

A Chrome extension that hides the pause screen ads on Netflix.

## Install

**From the Chrome Web Store:** *(link coming soon)*

**Manually:**
1. Download or clone this repo
2. Go to `chrome://extensions` → enable **Developer Mode**
3. Click **Load unpacked** → select this folder

## How it works

When you pause a video on Netflix, an ad is injected into the screen. This extension detects and hides that element instantly, so you just see your paused video.
