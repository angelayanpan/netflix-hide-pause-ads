# Privacy Policy for Netflix Hide Pause Ads

**Last updated: May 18, 2026**

## Overview

Netflix Hide Pause Ads is a Chrome extension that hides the pause screen ad element on Netflix. It does nothing else.

## Data Collection

This extension does **not** collect, store, transmit, or share any user data of any kind. This includes:

- No browsing history
- No personal information
- No usage analytics
- No crash reports
- No communication with any external server

## How it works

The extension runs a content script on netflix.com that watches for the pause ad element and hides it using CSS. No data ever leaves your browser.

## Third Parties

This extension does not use any third-party services, analytics tools, or remote code.
